# Changes

## 3.3
- Added Terms of Use and Privacy Policy; simplified license files.
- Log tabs are named "Results" and "Full log"; long-press a tab to rename it.
- Notification FORCE CLOSE closes only the app that is on screen.
- New dark theme colors.
- Animations for tabs, buttons, dialogs and log lines.
- The last state is saved: STOP stays STOP while Shizuku is off, cleanup finishes when Shizuku is back, and the state is restored after a reboot.
- Effects removed for an app are closed by their saved effect IDs.
- App icon added.
- versionCode 33 so Shizuku reloads the updated user service.
